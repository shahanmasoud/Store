# فاز ۲۴ — یکپارچه‌سازی ورودی‌های تعداد

## محدوده تحویل

- نقطه سفارش و مقدار اصلاح موجودی
- حداقل تعداد عمده و حداقل تعداد تخفیف
- حداقل تعداد فروش آنلاین و مقدار رزرو
- درصد تخفیف عمداً خارج از این برش باقی ماند، چون واحد و قواعد اعتبارسنجی متفاوتی دارد.

همه این فیلدها اکنون از ورودی اعشاری مشترک استفاده می‌کنند: نمایش فارسی و سه‌رقمی برای کاربر، در کنار نگهداری مقدار canonical انگلیسی برای اعتبارسنجی و API.

## تست خودکار

- `pnpm test:numbers`: چهار تست از چهار تست موفق
- `pnpm test:roles`: هفده تست از هفده تست موفق
- `pnpm build`: موفق با ۹۷۸ ماژول
- `git diff --check`: بدون خطا؛ فقط هشدار line-ending ویندوز

## تست دستی باقی‌مانده

در Chrome دسکتاپ و نمای موبایل `390 × 844`، برای هر شش فیلد تایپ رقم فارسی و انگلیسی، paste، حذف با Backspace، اعشار و حفظ محل نشانگر بررسی شود. ثبت فرم نیز باید مقدار صحیح را به backend بفرستد.
